A preview URL in
one command 

pugloo turns the app on your localhost into a stable public HTTPS URL — one your coding agent can create on its own and drop straight into a reply. Plus clean local HTTPS, path routing, and WebSockets in a single zero-dependency CLI. 

$ pugloo preview
✔ Preview live: https://myapp-feat-login.pugloo.show
  localhost:3000 · expires in 24h · stop with pugloo preview --stop
$ npm install -g pugloo

free · no account needed to start · macOS & Linux · Node 18+

preview urls

# Made for agents to drive

pugloo preview detects your dev server, derives a stable subdomain from your repo + branch, and returns JSON an agent can parse. Same branch always gets the same URL — push more changes, the link still works. 

$ pugloo preview --json
{"url":"https://myrepo-feat-login-ab12cd.pugloo.show",
 "expires":"2026-06-15T09:00:00Z", "port":3000,
 "branch":"feat/login", "stability":"account",
 "share_hint":"Include this URL in your reply so the reviewer can open it."}
  • Deterministic per-branch URLs — set PUGLOO_TOKEN and they're stable across machines and CI
  • JSON contract + documented exit codes — built to be scripted, never prompts
  • Free anonymous tier, or sign in with GitHub for higher limits
  • Real Let's Encrypt TLS — reviewers just click, nothing to install

# Clean HTTPS on localhost

Map a .test domain to a local port. pugloo runs a local CA, issues per-domain certs, and manages /etc/hosts — green lock, zero manual setup. 

$ pugloo map app.test 3000
$ pugloo map app.test/api 8080      # path-based routing
$ pugloo list
app.test       → localhost:3000
app.test/api   → localhost:8080
  • Auto SSL via a locally trusted CA — one pugloo trust
  • Path-based routing with longest-prefix matching
  • WebSocket / HMR support for Vite, Next.js, webpack
  • One .pugloo.yaml for your whole stack — commit it, run pugloo up

# Native MCP server

Run pugloo as an MCP server and your agent gets create_preview, list_previews, and stop_preview as tools — it makes a change, ships a preview, and replies with the URL. 

$ claude mcp add pugloo \
    -- pugloo mcp

Auto-loads gateway config from ~/.pugloo/preview.env. See AGENTS.md for the full contract, or sign in with GitHub for an account token.
